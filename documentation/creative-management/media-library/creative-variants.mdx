Preparing separate video files for different screen resolutions adds manual work and makes asset selection harder. Creative Variants lets users generate resolution variants from an eligible MP4 video, retain the Master, and choose the version that fits the target inventory.

This walkthrough follows all six frames in the supplied **Upload a File** design. Screenshots are design references, not production captures. The existing release record remains **Planned Release — 27 October 2026** until production deployment and QA are confirmed.

## Before you start

- Open **Library > Media Library** in your organization.
- Use an eligible MP4 video for variant generation. Images and Raw HTML5 are not transcoded.
- Uploading a creative and generating variants are separate actions. After upload, use the manual **Variant** action for an eligible MP4 creative and wait for generation to finish before using generated versions.
- Master retains the original file; documented profiles are High **1920 × 1080**, Medium **1280 × 720**, and Low **854 × 480**. Each file has a distinct Creative ID and can be assigned independently through the supported workflow.

## Read the library correctly

- **Hierarchy:** an expanded parent exposes indented related rendition rows. Other groups may remain collapsed.
- **Identity:** each shown rendition has its own **Creative ID**. Related filenames help identify a family but do not replace the ID.
- **Usage:** **In Use** and **Unused** describe each row separately. Upload completion is not a usage or campaign-delivery state.
- **Review:** compare **Dimension**, **Size**, **Format**, and filename before selecting a creative. Use **Search**, **All Types**, **All Usage**, and **Newest first** to locate it.
- **Scope:** tagging, compliance, and analytics are outside this Creative Variants release.

## Design boundaries

Frames **1** and **6** contain the same Media Library image in the supplied design. Both are retained to preserve the six-frame sequence; frame 6 is not evidence of a new completion state or a newly created asset. Filenames, dates, file sizes, percentages, and the upload badge are illustrative sample values, not limits or service guarantees.

The existing upload guide lists a **50 MB** file-size limit, while this mockup contains larger sample sizes. This walkthrough does not change or validate the upload limit. Check the current [Upload Creative](/documentation/creative-management/media-library/upload-creative) guide and confirm supported limits with Lynx Support when needed.

If a variant is missing or processing fails, contact Lynx Support with the Master creative name, Creative ID, upload time, and expected resolution.
