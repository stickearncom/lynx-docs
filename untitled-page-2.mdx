## Creative Variants

**Planned release: 27 October 2026 — draft, not yet released.**

Preparing separate video files for different screen resolutions adds manual work and makes asset selection harder. Creative Variants lets you generate resolution variants from an eligible video in the Media Library, then choose the version that fits your inventory.

### What is changing

For eligible MP4 video creatives, use the **Variant** action to generate resolution variants. Uploading a file and generating its variants are separate actions. The original file is kept as the **Master**, alongside the generated variants:

Each uploaded file and generated variant will have its own unique Creative ID. You will be able to select and assign each variant independently to the applicable inventory or campaign workflow.

### How to use it after release

1. Open the **Media Library** and select **Upload Creative** to upload your video.
2. Check **Upload Manager** for upload progress and completion. Upload completion does not mean variant generation has completed.
3. For an eligible MP4 video creative, select **Variant** to generate variants. Wait for generation to complete before using the generated versions.
4. Select the version that fits your target inventory and assign it through the supported inventory or campaign workflow.

### Find and review your creatives

- Use **All Types** and **All Usage** to filter the library by creative type and usage.
- Sort by **Newest first**, **Oldest first**, **Name A-Z**, or **Name Z-A**.
- Review creative information in the table, including **Type**, **Format**, **Dimension**, and **Uploaded** date.

No customer action is required before release. Generated variants are available after processing completes successfully.

### What stays the same

Images and Raw HTML5 creatives will not be transcoded. This planned update covers Creative Variants only; tagging, compliance, and analytics are not part of this release. The filters, sorting and table presentation described above accompany the demonstrated Media Library workflow.

For the existing upload workflow, see [Upload Creative](/documentation/creative-management/media-library/upload-creative).
