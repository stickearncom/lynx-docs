**Planned release: 02 November 2026 — not yet released.**

Understanding device behavior requires visibility into resource usage as well as connection status. An online status alone does not explain CPU, memory, disk, or network activity.

This update improves Device Telemetry charts and network-traffic visibility in Screen Details, helping you review available device usage data in one place.

## What is changing

- Redesigned Device Telemetry charts.
- Network-traffic information in Screen Details for supported ScreenApp devices.
- Fixes for missing CPU, Network Traffic, Disk Usage, and Memory graph data on ScreenApp Native devices.

## How to use after release

1. Open the screen you want to review in your inventory.
2. Open **Screen Details**, then **Usage Details**.
3. Review the available CPU, Network Traffic, Disk Usage, and Memory charts.

## Good to know

- Available data depends on telemetry reported by the device. An online connection does not by itself guarantee that all chart data is available.
- This update concerns device monitoring; it does not change your campaign setup.
- No action is required before release.

If expected data is missing, contact Lynx Support with the screen name, affected metric, and time of observation.

See [ScreenApp connection](/documentation/inventory/dooh/screens/screen-app/connection) for the existing connection workflow.
