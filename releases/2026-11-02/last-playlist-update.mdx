**Planned release: 02 November 2026 — not yet released.**

Previously, playlist-generation information was not visible to media owners in the portal, making it harder to check whether a playlist was current without asking for help.

Last Playlist Update displays the latest successful playlist generation or save time for ScreenApp screens, giving you a direct way to review playlist freshness.

## What is changing

- A **Last Playlist Update** field in the **Playlist/Playlog** tab.
- For ScreenApp screens, the latest successful generation or save timestamp, displayed in the screen's configured time zone.
- For HTML and API Integration screens, **N/A**, because their playlists are managed through an external CMS or ad server.

## How to use after release

1. Open the relevant inventory screen.
2. Open **Playlist/Playlog**.
3. Check **Last Playlist Update** beside the time-zone information.
4. If the timestamp remains older than expected, contact Lynx Support with the screen name and displayed time.

## Good to know

- The timestamp confirms successful playlist generation or saving, **not receipt by the player or actual playback**.
- If a later generation attempt fails or does not run, the last successful timestamp remains visible. This field is not a failure alert.
- Playlist generation schedules and playback behavior are unchanged.
- No action is required before release.

See [Playlist and Playlog](/documentation/inventory/dooh/playlist-playlog/overview) for the existing workflow.
